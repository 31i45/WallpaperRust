# ADR-003: 锁屏用 PersonalizationCSP 注册表而非 SHCore.dll

## 状态：已采纳

## 背景
Windows 提供多种设置锁屏壁纸的方式：
1. **`SHCore.dll` 的 `SetDesktopWallpaper` API** —— Win10 1803+ 支持，可同时设置桌面和锁屏
2. **写入 `HKLM\...\PersonalizationCSP` 注册表** + 复制文件到 `%ProgramData%\Microsoft\Windows\Lockscreen.jpg` —— 微软官方文档确认的锁屏设置方式
3. **组策略 / MDM 通道** —— 企业管理场景，不适用本项目

原版 Python WallpaperFlowZero 尝试了方法 1（调用 `SystemParametersInfoW` 加 `SPI_SETSCREENSAVEACTIVE` 变体），实际从未生效，是死代码。

## 决策
**使用 PersonalizationCSP 注册表方案**：
1. 将图片复制到 `%ProgramData%\Microsoft\Windows\Lockscreen.jpg`
2. 写入 `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\PersonalizationCSP`：
   - `LockScreenImagePath` = 图片路径（REG_SZ）
   - `LockScreenImageStatus` = 1（REG_DWORD）
3. **必须管理员权限**（HKLM + ProgramData 写入）

## 后果

好：
- 文档明确、行为可预期，Windows 10/11 全版本支持
- 代码量小（约 30 行），只需 fs::copy + 两个 RegSetValueExW 调用
- 失败时有明确的错误路径（权限不足 → RegOpenKeyExW 返回非 ERROR_SUCCESS → 静默返回 false）

坏：
- 依赖特定注册表路径和 CSP 行为，Windows 大版本更新可能移除该入口（极低概率，微软对 HKLM PersonalizationCSP 承诺稳定）
- 设置生效延迟 1-5 秒（Windows 读取 CSP 有内部轮询），不是实时可见

## 替代方案

| 方案 | 放弃理由 |
|---|---|
| SHCore.dll SetDesktopWallpaper | 在部分 Win10 版本上行为不一致；SetDesktopWallpaper 的锁屏参数（DESKTOP_WALLPAPER_MODE）文档不全，社区反馈较多"只改桌面不改锁屏"报告 |
| SystemParametersInfoW + SPI_SETDESKWALLPAPER | 只设置桌面壁纸，锁屏不受影响；原版 Python 代码试图变体调用但实际无效 |
| IDesktopWallpaper COM 接口 | 比 SHCore 更底层，同样有锁屏不生效的问题；且需要 CoCreateInstance 和接口查询，代码复杂度显著升高 |
